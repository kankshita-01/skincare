# GlowCare Landing Page

A skincare landing page created as part of The Odin Project Foundations Landing Page project.

## Built With

* HTML
* CSS
* Flexbox

## Features

* Header navigation
* Hero section
* Skincare information cards
* Quote section
* Call-to-action section
* Sign-up page
* Footer
